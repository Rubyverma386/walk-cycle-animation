## The Four Main Poses

A walk cycle is built from a repeating transfer of weight from one foot to the other.

1. **Contact:** the forward foot reaches the ground, legs apart. This sets the stride length.
2. **Down:** the body takes the weight and lowers slightly, knee bends.
3. **Passing:** the moving leg swings through under the body while the other leg supports.
4. **Up:** the body rises and the back heel lifts, ready for the next step.

The same sequence repeats for the opposite leg, and the arms swing opposite to the legs.

## Workflow

`Project Setup → Import Character Assets → Arrange Character Parts → Create Key Poses → Animate Arms and Legs → Preview → Correct Timing and Movement → Export`

## Character Assets

The character is built from separate symbols (not one flat image): head, face, eyes, eyebrows, hair, ear, cap, T-shirt, jacket, hands, hip, legs and shoes. They are grouped under the `Side_minkoo` Library folder and assembled in `Side_minkoo_mainrig`.
